# Local analysis protocol v0.1

- Original transcript is evidence, not a draft to overwrite.
- Refined text may adjust punctuation and readability but must preserve meaning, uncertainty, negation, contradictions, profanity, and emotional nuance.
- Do not invent events, motives, transitions, or diagnoses.
- Keep analysis separate from source and cite source passage IDs for claims.
- Label uncertain interpretations as uncertain.
- Topic frequency does not establish importance; sentiment estimates do not establish actual emotional state.
- Never transmit content to remote services without explicit, informed user action.
- Analysis can be disabled without impairing recording or journaling.
